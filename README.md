# Store Tec API - SIN CRUD
API REST ASP.NET Core .NET 10. Recursos: Productos, Categorías, Marcas y Promociones.
IMPORTANTE: no contiene POST, PUT, PATCH ni DELETE. Solo consultas GET.
Endpoints: /api/productos, /api/categorias, /api/marcas, /api/promociones.
Ejemplos: GET /api/productos ; GET /api/productos/1 ; GET /api/productos?buscar=Samsung ; GET /api/productos?categoriaId=1 ; GET /api/promociones?activas=true.
Ejecutar: dotnet restore && dotnet run
